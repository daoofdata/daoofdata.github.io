Data is as data does

The simplest pipeline that reveals meaning is the only one you need to maintain.

// The Dao of Data is is the quiet art of letting data flow without resistance. It acknowledges that data in and of itself is empty. Data is an infrastructure upon which meaning and appropriate use arises.
Manifesto
  1. 01
    Data as infrastructure Data are not isolated, tradable commodities, but constitute a foundational, collective resource. Meaning and usage is inextricably bound to the digital protocols and algorithms that process it.
  2. 02
    Informed simplicity An enlightened view of reality, founded discerning or creating clarifying patterns within complex mixtures of data. With deep experience, you learn what to leave out.
  3. 03
    Idempotent & observable A pure transform run twice produces the same stillness.
  4. 04
    Less is more The minimum code that works. No speculative abstractions.
